# Currency Converter

A currency converter built with React and Vite.

## Features

- Convert currencies using live exchange rates.
- Select the source and target currencies.
- Enter a custom amount.
- Displays the converted amount.
- Uses React Query for API data fetching and caching.

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Axios
- TanStack React Query
- ExchangeRate-API
